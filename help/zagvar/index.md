# Бичиг баримтын загвар

Апп дээр бэлэн загвар сонгож бичиг баримтаа бичих боломжтой. Бичих зуур үгийн алдаа шалгагдаж, баримт урьдчилан харах самбарт хэвлэгдэх хэлбэрээрээ харагдана. Дууссаны дараа Word, OpenDocument, PDF, LaTeX болон бусад өргөтгөлөөр хадгална.

## Албан бичиг

- [Өргөдөл](/zagvar/urgudul/) — байгууллага, албан тушаалтанд хандсан өргөдөл.
- [Хурлын тэмдэглэл](/zagvar/hurliin-temdeglel/) — хурлын дугаар, огноо, оролцогч, хэлэлцсэн асуудал, шийдвэр.

## Судалгаа

- [Судалгааны тайлан](/zagvar/tailan/) — бүлэг, хүснэгт, зураг, агуулгын жагсаалттай тайлан.
- [Судалгааны илтгэл](/zagvar/iltgel/) — слайд, илтгэгчийн тэмдэглэлтэй илтгэл.
- [Судалгааны өгүүлэл](/zagvar/ugulel/) — LaTeX дээр бичих эрдэм шинжилгээний өгүүлэл.

Албан бичиг, тайлан, илтгэлийн загвар Markdown хэлбэртэй, судалгааны өгүүлэл LaTeX хэлбэртэй. Дэлгэрэнгүйг [Файл засварлах](/zaavar/file/) хуудаснаас харна уу.
