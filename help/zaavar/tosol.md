# LaTeX төсөл

Олон `.tex` файл, зураг, ном зүйгээс бүрдэх LaTeX төслийг хөтөч дээр нээж, файл бүрийн үгийн алдааг шалгаад PDF болгон хөрвүүлэх боломжтой. LaTeX-ийг компьютертоо суулгах шаардлагагүй. Нийтлэл, бие даалт, ном болон beamer слайдыг хөрвүүлнэ.

![LaTeX бичвэр ба харагдац](/zaavar/img/tosol-haragdats.webp)

## Төсөл нээх

`Файл нээх` товчийг дарахад гарах цэсийн `LaTeX төсөл` хэсгээс нээх аргаа сонгоно:

- **Хавтас нээх** — компьютер дээрх төслийн хавтсыг сонгоно. Засвар тухайн хавтсандаа шууд хадгалагдана. Хавтсанд хандах зөвшөөрлийг хөтөч асууна.
- **Zip файл нээх** — `.zip` архивт шахсан төслийг нээнэ.
- **Git repo нээх** — github.com эсвэл gitlab.com дээрх repo-г нээнэ. Төслийг `бүлэг/нэр` хэлбэрээр бичиж, шаардлагатай бол салбар, хавтсыг зааж өгнө. Нууц repo-г нээхэд тухайн үйлчилгээнд нэвтэрнэ.

![Файл нээх цэсийн LaTeX төсөл хэсэг](/zaavar/img/tosol-neeh.webp)

Төслийн самбар хоосон үед ч эдгээр гурван товч самбарт харагдана.

![Хоосон төслийн самбар](/zaavar/img/tosol-hooson.webp)

Төсөлд 3000-аас ихгүй файл, нийт 200 MB-аас ихгүй хэмжээтэй байна.

## Төслийн самбар

Төсөл нээгдэхэд файлуудын мод бүхий самбар гарч ирнэ. Файл дээр дарж нээхэд түүний нэр дээд талд харагдана. Самбарын доод хэсгийн товчоор шинэ файл, шинэ хавтас үүсгэх, нэр солих, `Архивлах` товчоор төслийг `.zip` болгон татна. Файл, хавтсыг чирч зөөнө.

Хөрвүүлэлт эхлэх үндсэн `.tex` файл `үндсэн` гэсэн тэмдэгтэй харагдана. `\documentclass` болон `\begin{document}` бүхий файлыг автоматаар үндсэн файлд тооцох бөгөөд өөр файлыг `Үндсэн файл болгох` үйлдлээр сонгоно.

![Төслийн файлын мод ба үндсэн файл](/zaavar/img/tosol-mod.webp)

Төсөлд зургийн хавтас, өөрийн `.sty` багц болон бусад файлыг хамт байршуулж болно. Төслийн доторх PDF файл дээр дарахад түүнийг `Харагдац` самбарт нээж, файлын нэрийг самбарын гарчигт харуулна.

![Төслийн доторх PDF файлыг харах](/zaavar/img/tosol-pdf.webp)

Өөр программаар хавтсанд өөрчлөлт оруулсан бол `Дискнээс дахин унших` үйлдлээр шинэчилнэ.

## LaTeX бичих хэрэгсэл

LaTeX файл нээхэд бичвэрийн талбарын дээр LaTeX-ийн хэрэгслийн мөр гарна. Бүлэг, үсгийн хэлбэр, жагсаалт, томьёо, зураг, хүснэгт, холбоос, товъёгийг командыг нь цээжлэхгүйгээр оруулна.

**Бүлэг** цэсээс хэсэг, бүлэг, дэд бүлэг, хэсэг бүлэг, жижиг хэсэг, догол зэрэг гарчгийн төвшин болон баримтын гарчиг үүсгэх, агуулга, хураангуй, хавсралт, шинэ хуудсыг оруулна. Төсөлд ажиллах үед хэрэгслийн мөрийн эхэнд одоо нээлттэй файлын нэр харагдана.

![LaTeX бүлгийн цэс](/zaavar/img/tosol-bulag.webp)

**Орчин** цэсээс байршил (голлуулах, жижиг хуудас, зураг, хүснэгт, тайлбар), текст (ишлэл, шүлэг, хувиргахгүй), теорем (теорем, лемм, тодорхойлолт, жишээ, баталгаа) болон слайдын орчныг оруулна.


**Томьёо** цэсээс тусдаа мөрөнд эсвэл дугаартай томьёо, тэгшилсэн томьёо, нөхцөлт илэрхийлэл, зэрэг, язгуур, нийлбэр, хязгаар, матриц болон вектор, малгай зэрэг тэмдэглэгээг оруулна. Тэмдэгтийн цэсээс грек үсэг, харьцаа, үйлдэл, сумыг сонгоно.

![LaTeX томьёоны цэс](/zaavar/img/tosol-tomyo.webp)

Командын нэрийг бичиж эхлэхэд нөхөх санал гарч, `Tab` товчоор командын дараагийн хэсэгт шилжинэ. `alt + enter` дарахад жагсаалтад шинэ `\item` нэмнэ.

Бичиж зогсоход догол мөр, хоосон мөр жигд бус байвал талбарын баруун дээд буланд `Хэлбэржүүлэх` товч гарч, бичвэрийг жигдрүүлнэ.

## Хөрвүүлэх

`ctrl + enter` эсвэл `Хөрвүүлэх` товчоор төслийг PDF болгон хөрвүүлж, `Харагдац` самбарт үзүүлнэ. `ctrl + shift + enter` дарах эсвэл `Хөрвүүлэх` товчийг удаан дарвал бичиж зогсох бүрд автоматаар хөрвүүлнэ. Баримт хэт том бол автомат хөрвүүлэлт зогсож, гараар хөрвүүлнэ.

`Харагдац` самбарын дээд хэсэгт:

- Хуудасны дугаар — дарж хүссэн хуудас уруугаа очно.
- `PDF татах` — хөрвүүлсэн PDF файлыг татна.
- `−`, `+` — томруулах, жижгэрүүлэх. `ctrl` дарсан чигтээ хулганын дугуйг эргүүлж мөн томруулна.
- Бараан горимд `Хуудсыг цагаанаар харах` товчоор хуудсыг цагаан эсвэл бараан өнгөөр харуулна.

![Бараан горим — бараан хуудас](/zaavar/img/tosol-pdf-baraan.webp)
![Бараан горим — цагаан хуудас](/zaavar/img/tosol-pdf-tsagaan.webp)

LaTeX багцуудыг анх хөрвүүлэх үед интернетээс татна. Нэг удаа онлайнаар хөрвүүлсний дараа офлайн ч хөрвүүлэх боломжтой.

LaTeX командын дотор үгийн алдаа шалгагдахгүй, зөвхөн бичвэр шалгагдана.

## Хадгалах ба commit

- Хавтсаар нээсэн төслийн засвар хавтсандаа хадгалагдана. Хавтсанд шууд бичих боломжгүй хөтөч дээр засварласан файлууд `Татаж авсан файлууд` хавтас уруу татагдах бөгөөд анхны файлыг тэдгээрээр солино.
- Төслийг бүхэлд нь `Архивлах` товчоор `.zip` архив болгож татаж авна.
- Git repo-оор нээсэн төслийн засварыг тайлбар бичээд commit хийнэ. Тэр хооронд repo-д өөр хүн өөрчлөлт оруулсан бол зөрчлийг шийдвэрлэх цонх гарч, аль хувилбарыг үлдээхээ сонгоно.
