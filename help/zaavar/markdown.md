# Markdown бичвэр ба хүснэгт

Албан бичиг, тайлан, илтгэлийн [загварууд](/zagvar/) Markdown хэлбэртэй. Markdown нь энгийн бичвэр дотор тусгай тэмдэгтээр гарчиг, жагсаалт, хүснэгт зэргийг тэмдэглэдэг бичлэг юм. Бичих зуур баримт урьдчилан харах самбарт хэвлэгдэх хэлбэрээрээ харагдана.

## Хэрэгслийн мөр

Markdown горимд бичвэрийн талбарын дээр хэрэгслийн мөр гарна. Тэмдэгтүүдийг цээжлэх шаардлагагүй, товчоор оруулна:

| Товч | Үйлдэл | Markdown бичлэг |
|---|---|---|
| B, I | Тод, налуу | `**тод**`, `*налуу*` |
| H1–H4 | Гарчиг, дэд гарчиг | `# Гарчиг`, `## Дэд гарчиг` |
| Aa | Том, жижиг үсэг ээлжлэх | |
| Зэрэгцүүлэх | Зүүн, голлуулах, баруун | `::: {.center}` … `:::` |
| Гарын үсэг | Гарын үсгийн мөр | |
| Зүйлчлэх, дугаарлах | Жагсаалт | `- зүйл`, `1. зүйл` |
| Ишлэл | Ишлэл | `> ишлэл` |
| Хүснэгт | Хүснэгт оруулах | доороос харна уу |
| Зураг, холбоос | Зураг, холбоос оруулах | `![тайлбар](зураг.png)`, `[нэр](хаяг)` |
| Хуудас таслах | Дараагийн хуудаснаас эхлэх | |

## Хүснэгт байгуулах

`Хүснэгт` товчийг дарахад дараах хүснэгт оруулна:

```demo
::: {width="100%" .grid}
| Багана 1 | Багана 2 |
| --- | --- |
|     |     |
:::
```

- Эхний мөр нь толгой мөр, хоёр дахь мөр нь толгойг биеэс тусгаарлана.
- Нүд бүрийг `|` тэмдгээр тусгаарлана. Шинэ багана нэмэхдээ мөр бүрд `|` нэмнэ, шинэ мөр нэмэхдээ мөрийг хуулж бичнэ.
- Толгой мөргүй хүснэгт хийхдээ эхний мөрийн нүднүүдийг хоосон үлдээнэ.
- `::: {…}` ба `:::` мөрүүд хүснэгтийн тохиргоог агуулна. Тохиргоо хэрэггүй бол эдгээр мөрийг бичихгүй байж болно.

## Хүснэгтийг сунгах

`width` нь хүснэгтийн өргөнийг хуудасны өргөнд харьцуулан хувиар заана. `width="100%"` бол хүснэгт хуудасны өргөнөөр бүтэн сунана, `width="60%"` бол хуудасны 60 хувийг эзэлнэ. `width`-ийг бичээгүй бол хүснэгт агуулгынхаа хэмжээгээр байна.

`width` заасан үед баганын өргөн нь тусгаарлах мөрийн зураасны тоонд харьцаатай байна. Жишээлбэл, эхний багана хоёр дахиасаа гурав дахин өргөн байх бол:

```demo
::: {width="100%"}
| Нэр | Тоо |
| --------- | --- |
| Бензин | 120 |
:::
```

## Мөрийн өндөр

`row` нь мөр бүрийн өндрийг см эсвэл мм-ээр заана. Хүснэгтийг гараар бөглөх маягт хэлбэрээр хэвлэх үед бичих зай өгөхөд тохиромжтой:

```demo
::: {width="100%" .grid row="1.5cm"}
| Огноо | Гарын үсэг |
| --- | --- |
|     |     |
|     |     |
:::
```

Толгой мөрийн өндөр өөрчлөгдөхгүй. Мөрийн өндөр 10 см-ээс ихгүй байна.

## Шугам

| Тохиргоо | Шугам |
|---|---|
| бичихгүй | Зөвхөн толгой мөрийн дээр, доор болон хүснэгтийн доод талд шугам татна |
| `.lines` | Мөр бүрийн доор хэвтээ шугам татна |
| `.grid` | Мөр, багана бүрийг тусгаарлаж бүх шугамыг татна |

```demo
::: {width="100%" .lines}
| Хэлтэс | Машин |
| --- | --- |
| Борлуулалт | 4 |
| Санхүү | 2 |
:::
```

Зөвхөн баганыг тусгаарлах босоо шугамын тохиргоо одоогоор байхгүй.

## Нүдний зэрэгцүүлэлт

Багана бүрийн бичвэрийг тусгаарлах мөрөнд `:` тэмдэг нэмж зэрэгцүүлнэ:

| Тусгаарлах мөр | Зэрэгцүүлэлт |
|---|---|
| `---` эсвэл `:---` | Зүүн тийш |
| `:---:` | Голлуулах |
| `---:` | Баруун тийш |

```demo
| Нэр | Тайлбар | Дүн |
| :--- | :---: | ---: |
| Бензин | сараар | 1 200 000 |
```

Тоон баганыг баруун тийш зэрэгцүүлбэл орон оронтойгоо тэгшрэх тул уншихад хялбар болно.

## Хүснэгтийн байрлал

Хуудасны өргөнөөс нарийн хүснэгтийг `.left`, `.center`, `.right` тохиргоогоор зүүн, голд эсвэл баруун талд байрлуулна:

```demo
::: {width="60%" .grid .center}
| Үзүүлэлт | Утга |
| --- | --- |
| Машины тоо | 12 |
:::
```

Тохиргоонуудыг нэг мөрөнд хамт бичиж болно, жишээлбэл `::: {width="80%" .grid row="1cm" .center}`.

## Хадгалах

Хүснэгтийн тохиргоо Word, PDF, LaTeX болон PowerPoint өргөтгөлөөр хадгалахад хадгалагдана. Хадгалах тухай [Файл засварлах](/zaavar/file/) хуудаснаас харна уу.
