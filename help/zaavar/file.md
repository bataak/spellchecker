# Файл засварлах

## Нээх боломжтой файлууд

Файлаа бичвэрийн талбар уруу шууд зөөж тавих эсвэл `ctrl + o` дарж нээнэ. Дараах төрлийн файлыг нээх боломжтой:

| Төрөл | Өргөтгөл |
|---|---|
| Энгийн бичвэр | `.txt` |
| Markdown | `.md`, `.markdown` |
| LaTeX | `.tex`, `.ltx` |
| Microsoft Office | `.docx`, `.pptx` |
| OpenDocument | `.odt`, `.odp` |
| PDF | `.pdf` |
| Архив | `.zip` |

Хэд хэдэн файл нээхэд тус бүр нь тусдаа талбарт нээгдэнэ.

## Баримт бичгийн алдаа засварлах

Энэхүү онлайн апыг ашиглан Microsoft Office Word, PowerPoint программуудын файлыг (`*.docx`, `*.pptx`) засах боломжтой. Тодруулбал, `.docx`, `.pptx` файлууд нь `ZIP` төрлийн шахсан архив файл байдаг бөгөөд дотроо нь `word/document.xml` эсвэл `ppt/slides/slideN.xml` гэсэн `XML` файлд бичвэр агуулагддаг. Энэхүү веб ап нь уг бичвэр агуулсан файлыг дуудаж засварлах тул бичвэрт агуулагдах зураг, хүснэгт болон бусад форматжуулалтуудыг хөндөхгүй. Улмаар бичвэрийн алдааг засаж дууссаны дараа хадгалах товчийг дармагц тэрхүү бичвэрийн файлын үгийн алдаа засагдаж, бусад форматжуулалт хуучин хэвээр байх болно.

OpenDocument (`*.odt`, `*.odp`) файлыг мөн адил засна.

Түүнчлэн `pdf` файлын бичвэрийн алдааг хянах боломжтой. Сканердсан, текстийн давхаргагүй PDF файлыг уншиж чадахгүй.

[Word, PowerPoint, PDF файлын алдаа засварлах](https://www.youtube.com/watch?v=bxQT52J3zTE)

## Өөр өргөтгөлөөр хадгалах

`ctrl + s` дарахад бичвэр нээсэн файлынхаа өргөтгөлөөр хадгалагдана. Өөр өргөтгөл сонгохдоо хадгалах товчийг `shift`-тэй хамт эсвэл удаан дарна, эсвэл `ctrl + alt + s` дарна.

Markdown загвараар бичсэн бичвэрийг Word, OpenDocument, PDF, LaTeX болон энгийн бичвэр болгон, илтгэлийг PowerPoint болгон хадгалах боломжтой.

## Хэвлэх

Хэрэгслийн мөрийн `Хэвлэх` товч эсвэл `ctrl + p` дарж баримтыг хэвлэнэ. `Хэвлэх` товч дараах тохиолдолд гарна:

- **Markdown загвар ба Markdown файл** — өргөдөл, хурлын тэмдэглэл, тайлан болон Markdown файлыг загварын хуудасны хэмжээ, үсгийн хэлбэр, хүснэгтийн тохиргоотойгоор нь хэвлэнэ. Илтгэлийн слайд бүр тусдаа хуудсанд хэвлэгдэнэ.
- **LaTeX бичвэр ба төсөл** — бичвэрийг эхлээд PDF болгон хөрвүүлээд хэвлэнэ. Хөрвүүлэлтэд алдаа гарвал хэвлэхгүй бөгөөд алдааны мэдэгдэл гарна.

Энгийн бичвэрийн талбарт `Хэвлэх` товч гарахгүй.

Хөтчийн хэвлэх цонх нээгдэхэд хэвлэгчээ сонгоно. Хэвлэгчийн оронд PDF болгон хадгалах сонголтыг сонговол баримтыг PDF файл болгон авна.

## Markdown ба LaTeX

Албан бичиг, тайлан, илтгэлийг Markdown, судалгааны өгүүллийг LaTeX хэлбэрээр бичихэд зориулсан бэлэн загварууд бий. Загвар бүрийн тайлбарыг [Баримт бичгийн загвар](/zagvar/), Markdown бичвэр болон хүснэгтийн тохиргоог [Markdown бичвэр ба хүснэгт](/zaavar/markdown/) хуудаснаас харна уу.

Markdown болон LaTeX бичвэрийг бичих явцад урьдчилан харах самбарт үзүүлнэ. `ctrl + enter` дарж баримтыг хөрвүүлэх, `ctrl + shift + enter` дарж бичиж зогсох бүрд автоматаар хөрвүүлэх горимд шилжинэ. LaTeX бичвэрийн тусгай тэмдэгт, команд болон томьёон дотор үгийн алдаа шалгагдахгүй.
