# Файл засварлах

## Нээх боломжтой файлууд

Файлаа бичвэрийн талбар уруу шууд зөөж тавих эсвэл `ctrl + o` дарж нээнэ. Дараах төрлийн файлыг нээх боломжтой:

| Төрөл | Өргөтгөл |
|---|---|
| Энгийн бичвэр | `.txt` |
| Markdown | `.md`, `.markdown` |
| LaTeX | `.tex`, `.ltx` |
| Microsoft Office | `.docx`, `.pptx` |
| OpenDocument | `.odt`, `.odp` |
| PDF | `.pdf` |
| Архив | `.zip` |

Хэд хэдэн файл нээхэд тус бүр нь тусдаа талбарт нээгдэнэ.

## Баримт бичгийн алдаа засварлах

Энэхүү онлайн апыг ашиглан Microsoft Office Word, PowerPoint программуудын файлыг (`*.docx`, `*.pptx`) засах боломжтой. Тодруулбал, `.docx`, `.pptx` файлууд нь `ZIP` төрлийн шахсан архив файл байдаг бөгөөд дотроо нь `word/document.xml` эсвэл `ppt/slides/slideN.xml` гэсэн `XML` файлд бичвэр агуулагддаг. Энэхүү веб ап нь уг бичвэр агуулсан файлыг дуудаж засварлах тул бичвэрт агуулагдах зураг, хүснэгт болон бусад форматжуулалтуудыг хөндөхгүй. Улмаар бичвэрийн алдааг засаж дууссаны дараа хадгалах товчийг дармагц тэрхүү бичвэрийн файлын үгийн алдаа засагдаж, бусад форматжуулалт хуучин хэвээр байх болно.

OpenDocument (`*.odt`, `*.odp`) файлыг мөн адил засна.

Түүнчлэн `pdf` файлын бичвэрийн алдааг хянах боломжтой. Сканердсан, текстийн давхаргагүй PDF файлыг уншиж чадахгүй.

[Word, PowerPoint, PDF файлын алдаа засварлах](https://www.youtube.com/watch?v=bxQT52J3zTE)

## Өөр өргөтгөлөөр хадгалах

`ctrl + s` дарахад бичвэр нээсэн файлынхаа өргөтгөлөөр хадгалагдана. Өөр өргөтгөл сонгохдоо хадгалах товчийг `shift`-тэй хамт эсвэл удаан дарна, эсвэл `ctrl + alt + s` дарна.

Markdown загвараар бичсэн бичвэрийг Word, OpenDocument, PDF, LaTeX болон энгийн бичвэр болгон, илтгэлийг PowerPoint болгон хадгалах боломжтой. `ctrl + p` дарж хэвлэнэ.

## Markdown ба LaTeX

Албан бичиг, тайлан, илтгэлийг Markdown, судалгааны өгүүллийг LaTeX хэлбэрээр бичихэд зориулсан бэлэн загварууд бий. Загвар бүрийн тайлбарыг [Бичиг баримтын загвар](/zagvar/) хуудаснаас харна уу.

Markdown болон LaTeX бичвэрийг бичих зуур урьдчилан харах самбарт үзүүлнэ. `ctrl + enter` дарж баримтыг хөрвүүлэх, `ctrl + shift + enter` дарж бичиж зогсох бүрт автоматаар хөрвүүлэх горимд шилжинэ. LaTeX бичвэрийн тусгай тэмдэгт, команд, томьёо дотор үгийн алдаа шалгагдахгүй.

## Төсөл

Олон файлаас бүрдэх LaTeX эсвэл Markdown төслийг хавтсаар нь эсвэл `.zip` архиваар нээж засах боломжтой. Мөн github.com болон gitlab.com дээрх repo-г нээж, засвараа commit хийж болно. Төслийг бүхэлд нь `.zip` архив болгож татаж авна.

## Үсэг таниулах

Хуучны баримт бичиг болон цөөн тохиолдолд хуучны `keyboard layout` ашиглаж байгаагаас болж баримт бичгийн үсгийн код танигдахгүй буюу `cp1251` кодчиллоор бичигддэг (тухайн хэрэглэгчийн хувьд тусгай фонт суулгасан байх тул уг ялгаа анзаарагдахгүй). Энэ тохиолдолд бичвэрийн талбарт `Үсэг таниулах` гэсэн товч талбарын баруун дээд буланд гарч ирнэ. Өөрөөр хэлбэл энэ товчлуурын тусламжтайгаар хуучин кодчиллоор бичигдсэн текстийг юникод болгон хөрвүүлэх боломжтой юм.
