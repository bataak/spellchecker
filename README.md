# Монгол үгийн алдаа шалгагч

Интернет хөтчид зориулсан офлайнаар ажиллан монгол болон англи хэлний үгийн алдаа шалгагч.

Шалгах ажиллагаа зөвхөн таны төхөөрөмж дээр хийгддэг тул мэдээлэл гуравдагч серверт илгээгдэхгүй,
суулгах болон бүртгүүлэх шаардлагагүй, ашиглахад үнэ төлбөргүй, нээлттэй эх болно.
