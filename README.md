# Монгол үгийн алдаа шалгагч

Браузер дээр шууд ажилладаг, монгол (болон англи) хэлний үгийн алдаа шалгагч.
Бүх шалгалт **таны төхөөрөмж дээр** хийгддэг — бичсэн текст сервер рүү
илгээгддэггүй, суулгац, бүртгэл шаардлагагүй, үнэ төлбөргүй, нээлттэй эх.

👉 Туршиж үзэх / эх код: https://github.com/bataak/spellchecker

## Энэ төсөл юунд хэрэгтэй вэ

Монгол хэлэнд үнэ төлбөргүй, нээлттэй, офлайн ажилладаг үгийн алдаа шалгагч
ховор. Ихэнх онлайн шалгагч таны текстийг гадны сервер рүү илгээдэг бөгөөд энэ
нь нууцлалын асуудал дагуулдаг. Энэ төсөл өөр замаар явдаг:

- **Нууцлал.** Шалгалт бүхэлдээ браузер дотор хийгддэг тул текст таны
  төхөөрөмжөөс гардаггүй.
- **Офлайн.** PWA (Service Worker) тул анх ачаалсны дараа интернетгүйгээр ажиллана.
- **Суулгацгүй, үнэгүй.** Вэб хаягаа нээхэд л болно — апп ч, бүртгэл ч хэрэггүй.
- **Монгол + англи.** Хэдэн толийг зэрэг ачаалж, хэлийг автоматаар таньж саналаа өгнө.
- **Нээлттэй эх.** Хэн ч fork хийж, өөрийн вэбд монгол алдаа шалгалт нэмж,
  GitHub Pages дээр үнэгүй байршуулж болно.

**Хэнд зориулсан бэ:** монголоор бичдэг хэн бүхэн — сэтгүүлч, оюутан, редактор,
орчуулагч, ажилтан — мөн өөрийн бүтээгдэхүүндээ монгол алдаа шалгалт суулгахыг
хүсэгч хөгжүүлэгчид.

**Толь:** Энэ нь Hunspell-д суурилсан
[bataak/dict-mn](https://github.com/bataak/dict-mn) монгол толийг (≈60 мянган
үндэс, тэдгээрийн 2 тэрбум гаруй хувилбар) браузерт авчирч ашигладаг.

---

## Хэрхэн ажилладаг (товчоор)

Апп эхлээд жинхэнэ Hunspell-ийг (**hunspell-wasm**, монгол нийлмэл үгийг бүрэн
дэмждэг) ачаалж үзээд, ямар нэг шалтгаанаар амжилтгүй бол цэвэр JavaScript дээр
ажилладаг **nspell** руу автоматаар шилждэг — тул апп ямар ч орчинд ажиллана.
Толь, engine хоёр CDN-ээс биш, багцлагдан (bundle) ордог тул найдвартай. Гаралт
нь бүхэлдээ статик файл учир GitHub Pages дээр байршуулж, Service Worker-ээр
офлайн ажиллуулах боломжтой.

Статус мөрөнд аль engine идэвхтэйг харуулна:

- **монгол, англи** — толиуд амжилттай ачаалсан.
- **hunspell-wasm амжилтгүй (nspell ашиглаж байна)** — нөөц engine руу шилжсэн
  (монгол нийлмэл үгийн нарийвчлал арай бага).

## 1. Толинуудаа нэмэх

Толины файлуудыг `public/dict/` дотор (UTF-8) байрлуулна:

```
public/dict/mn_MN.aff   public/dict/mn_MN.dic
public/dict/en_GB.aff   public/dict/en_GB.dic
public/dict/en_US.aff   public/dict/en_US.dic
```

эсвэл ZIP-ээр (татах хэмжээ бага):

```bash
./pack-dict.sh        # public/dict/dictionaries.zip үүсгэнэ
```

Толь татах:

- Монгол — https://github.com/bataak/dict-mn
- Англи — https://github.com/LibreOffice/dictionaries
  (`en/` хавтас доторх `en_GB.*`, `en_US.*` файлуудыг ашиглана)

Бүх файл UTF-8 байх ёстой (`.aff` дотор `SET UTF-8`).

## 2. Локалоор ажиллуулах

```bash
npm install
npm run dev       # хөгжүүлэлт
npm run build     # -> dist/ (статик)
npm run preview   # build-ийг шалгах
```

> Тэмдэглэл: офлайн кэш (Service Worker) зөвхөн `build`-ийн дараа ажиллана,
> `dev` горимд анхдагчаар идэвхгүй.

## 3. GitHub Pages

**Автомат тохиргоо:** `main` руу push → `Settings → Pages → Source = GitHub Actions`.
`base`-ийг repo нэрээр автоматаар тааруулна.

**Гар тохиргоо:** `npm run build` → `dist/`-ийг `gh-pages` салбарт тавина. Энэ
тохиолдолд `vite.config.js` доторх `base`-ийг repo нэрээр солино (`/REPO/`).

`base`: project page → `/REPO/`; user/org page эсвэл custom domain → `/`.

## 4. Толь шинэчлэх ба кэш

Анх ачаалсны дараа толь нь Service Worker-ийн кэшэд хадгалагдах тул дараагийн
оролтуудад дахин татагдахгүй (офлайн ч ажиллана). Кэш нь хугацаагаар биш,
файлын агуулгын хувилбараар удирдагддаг.

Толио шинэчлэхэд зөвхөн `public/dict/`-ийн файлаа сольж, **дахин build/deploy**
хийнэ. PWA `autoUpdate` тул хэрэглэгчийн дараагийн оролтод зөвхөн өөрчлөгдсөн
толь татагдаж, ихэвчлэн нэг удаа reload хийсний дараа шинэ толиор ажиллана.
(Build алгасч зөвхөн файл сольвол кэш шинэчлэгдэхгүйг анхаараарай.)

## Ажиллагаа

- Үг бичих явцад тасралтгүй шалгахгүй — **зай / таслал / цэг / Enter** зэргээр үг
  төгсгөх, эсвэл богино завсарын дараа л шалгана (гүйцэтгэлд ээлтэй).
- Алдаатай үгийг бичвэрийн ард давхарласан давхарга дээр улаан долгионт зураасаар
  тэмдэглэнэ — textarea-гийн агуулгыг өөрчлөхгүй, зөвхөн харагдах давхаргыг тусад
  нь зурдаг.
- Улаанаар зурсан үг дээр дармагц зөв бичлэгийн саналууд гарч, сонгоход баримт
  даяарх ижил үгсийг (том/жижиг үсгийг хадгалан) солино. Гар утсанд санал болгох
  цонх гарны ард үлдэхгүйгээр үгийг дээш гүйлгэн харуулна.
- Товчлол/тоонд нөхцөл залгасан хэлбэрийг (жишээ нь **АНУ-ын**, **2012-ны**,
  **25-аас**) алдаа гэж тооцохгүй.
- Бүх дэлгэцэд (гар утас, PC) хуудас гүйлгэхгүйгээр багтаж, зөвхөн бичвэр дотроо гүйнэ.
- `hunspell-wasm`-ийн wasm нь JavaScript дотроо суусан (SINGLE_FILE) тул нэмэлт
  тохиргоо шаардлагагүй.

## Лиценз

Аппын эх код болон тус тусдаа ачаалагдах толинуудын лиценз өөр өөр. Толь нь
өөрийн лицензтэй (жишээ нь bataak/dict-mn нь LPPL) тул дахин түгээхдээ тухайн
толины нөхцөлийг баримтална.
